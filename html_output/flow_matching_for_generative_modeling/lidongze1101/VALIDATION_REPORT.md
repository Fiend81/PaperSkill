## 3. 数值测试

### 3.1 条件场加权（§3.1）

默认 `t=0.5`、`x=(-0.35,0.55)`：

- 权重：`[0.193543, 0.779517, 0.026940]`
- 权重和：`1.000000000000`
- 边缘场：`(0.252003, 0.947465)`
- 统一比例：`37.49 px/单位`；红色边缘箭头约 `36.8 px`，默认状态可见。
- `t=0.95` 时权重和仍为 1，`u_t(x)=(3.349,7.889)`，边缘箭头约 `69 px`；无密度下溢。

### 3.2 高斯密度（§2）

`p_t(x|x1)=N(t x1,[1-(1-σ_min)t]²)` 在 `[-10,10]` 上积分：

| t | 积分 | 峰值 |
| --- | ---: | ---: |
| 0 | 1.00000000 | 0.398942 |
| 0.5 | 1.00000000 | 0.759890 |
| 0.8 | 1.00000000 | 1.662260 |
| 1.0 | 1.00000000 | 7.979 |

自适应纵轴：`t=0` 为 0–0.50；`t=1` 为 0–9.18；固定刻度为 0–9.50。曲线高度与密度值一致。

### 3.3 OT 条件场恒等式（§4）

对多组 `t∈{0.1,0.45,0.8,0.95}`、`σ_min∈{0.02,0.1,0.4}`：

`u_t(ψ_t(x0)|x1)=dψ_t/dt`

最大绝对差 `6.66e-16`；页面默认读数差 `2.22e-16`。

### 3.4 VP/OT 轨迹（§5，`σ_min=0.05`）

固定 `x0=(-1.4,0.8)`、`x1=(1.5,0.8)`：

- OT 相对自身直线偏离：`1.52e-16`
- 扩散相对自身直线偏离：`0.329`
- OT 端点偏移 `|ψ₁−x₁|`：`0.081`
- 扩散起点偏移：`0.011`
- 路径长度：OT `2.830`，扩散 `2.994`

说明：OT 条件路径仍是直线，但端点是 `x1+σ_min x0`，落在 `x1` 附近窄高斯内；VP 扩散有限时间起点略有偏移。页面已分别显示目标均值与实际端点/起点。

### 3.5 真实 ODE 求解器（§6）

教学玩具向量场，参考解为 4096 步 RK4：

| 求解器 | 步数 | NFE | 终点误差 |
| --- | ---: | ---: | ---: |
| Euler | 8 | 8 | `2.58e-2` |
| Midpoint | 8 | 16 | `5.03e-4` |
| RK4 | 8 | 32 | `2.16e-7` |
| Euler | 32 | 32 | `6.37e-3` |
| Midpoint | 32 | 64 | `2.96e-5` |
| RK4 | 32 | 128 | `8.66e-10` |

页面 N=8 的 UI 测试与上表一致；64 步 + 1 步 Midpoint 的 NFE 为 2，符合每步 2 次评估。

### 3.6 真实梯度下降（§7）

`L(θ)=0.5(θ−2)²`，从 `θ=-2.5` 开始，10 步：

| 学习率 η | 最终 θ | 最终损失 | 解释 |
| ---: | ---: | ---: | --- |
| 0.05 | -0.694316 | 3.630 | 收敛缓慢 |
| 0.35 | 1.93942 | 1.835e-3 | 稳定收敛 |
| 1.5 | 1.99561 | 9.656e-6 | 稳定收敛 |
| 2.5 | -257.493 | 3.367e4 | 真实发散 |

### 3.7 伯努利小批量估计（§3.2）

`Y=0.5±√1.6`，`L_CFM=L_FM+0.8`：

- 理论差：始终 `0.800`；理论斜率：`dL_FM/dθ=dL_CFM/dθ=θ-0.5`。
- 经验 CFM 曲线由真实随机样本计算；单次实验的经验差不必等于 0.8。
- UI 测试示例：batch=32 时样本均值 `0.737`，经验梯度 `-0.537`，SE `0.224`；切到 batch=128 后样本均值 `0.559`，SE `0.112`。
- “重置”后：`θ=0.20`、小批量关闭、batch=32、显示差值选中，经验损失/梯度/样本均值/SE 均显示 `—`。
- 单次实验不保证 batch 越大误差越小；页面用 SE `√(1.6/n)` 说明统计收敛趋势，不制造确定性单调动画。
